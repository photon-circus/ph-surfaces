# v0.1 traceability checklist

Maps each v0.1 contract claim from
([#1](https://github.com/photon-circus/ph-surfaces/issues/1)) to its tests,
documentation, and CI gate. Remaining release actions — crate version,
`publish`, changelog close-out, tag, and upload — are governed by
[`RELEASING.md`](../RELEASING.md). This file is repository material; it is
not part of the packaged crate (the `include` allowlist in `Cargo.toml` and
the exact file-set assertion in the `package build` check keep `docs/` out of
the artifact).

Test names are the Rust `fn` names. `src/…` tests are unit tests;
`tests/conformance/…` tests are the black-box suite, which goes through the
public API only and compares against an independent `i128` reference. Doc
sections refer to `README.md` headings and the crate-level rustdoc in
`src/lib.rs` (`cargo doc`).

Nothing in this file is a claim of measurement: no cycle counts, WCET, or
device accuracy are asserted anywhere in the crate. The committed
[`docs/code-size-snapshot.txt`](code-size-snapshot.txt) is labelled
non-normative: it is not a guarantee, not total flash, and not WCET.

## Explicit v0.1 non-goals (kept out)

Documented in README "Out of scope" and rustdoc § Not in v0.1: no `ph-curves`
dependency or shared arithmetic crate; no inverse lookup; no other
dimensions, axis widths, or output types; no scattered points, irregular
meshes, bicubic interpolation, extrapolation, or fitting; no dynamic grids,
mutation, caching, allocation, `unsafe`, or floating point; no runtime
metadata, units, provenance, or generated reports; no host generation, CLI,
formula ingestion, or fitting; no device-specific equations, catalogs,
filtering, fusion, scheduling, buses, GPIO, async, or storage. Host-side
generation and a shared interpolation crate remain out of v0.1.
Runtime-selectable strategies and runtime-generated indexes are also excluded.
A direct coordinate-to-cell LUT remains deferred until a concrete consumer
provides its coordinate domain and latency/jitter bound, target/profile
measurements showing Bucketed misses that bound, a sufficient static-data
budget, and a reproducible generation and validation plan.

## Not proven, not claimed

Every Rust target other than the host and the two representative bare-metal
targets; Xtensa; cycle counts; code-size ceilings; hard real-time WCET; total
RAM, flash, or binary cost; exhaustive coverage of the full `u16 × u16` range
(it is sampled under a stated rule; only the small declared domains are
enumerated exhaustively); any device, vendor, sensor, or measurement accuracy.
The committed code-size snapshot is labelled non-normative and is none of
those claims.
