xtask -- the ph-surfaces verification gate

USAGE
  cargo xtask ci [options]
  cargo xtask list

OPTIONS
  --profile <dev|full|release>  which checks to run (default: full)
  --only <name>                 run one named check; repeatable
                                (incompatible with --profile release)
  --nightly <toolchain>         toolchain for the core-only proofs
                                (default: nightly; must be
                                nightly-YYYY-MM-DD in the release profile)
  --skip-embedded               skip checks that need a bare-metal target
  --fail-fast                   stop at the first failure
  --root <dir>                  operate on a checkout other than the cwd

PROFILES
  dev      source ratchets and the host contract; the inner loop
  full     everything runnable here; a missing optional tool is a SKIP
  release  release evidence; every would-be SKIP is recorded as a FAIL

A skipped check is not a passed check.
